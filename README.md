# Модуль учёта времени для системы управления задачами

Дополнительное задание по дисциплине "Проектирование и разработка бизнесориентированного ПО".

##  Выполненные требования
1. Возможность старта/остановки таймера для задачи.
2. Учёт общего затраченного времени.
3. Генерация отчетов по времени.
4. Интеграция с существующей системой задач (`TaskManager`).

## Дополнительные функции
- **Валидация состояний**: система предотвращает дублирование активных таймеров для одной задачи и попытку остановки несуществующего таймера.
- **Экспорт в CSV**: метод `export_report_to_csv` позволяет выгружать детальные метрики времени для дальнейшего бизнес-анализа.

## Структура проекта
- `task_system.py` — базовая система задач (из лекции).
- `time_tracker.py` — разрабатываемый модуль учёта времени.
- `test_time_tracker.py` — модульные тесты (покрытие 20% оценки).
- `main.py` — точка входа, демонстрирующая интеграцию.
